# CampusOS — submission worksheet

## Project description

CampusOS is a City University campus hub for sharing academic resources,
finding sourced campus guidance, joining club events and tracking student
support requests. Its four modules save records in Supabase and enforce
Student, Teacher and Admin permissions through database policies.

## Problem and CU use cases

Students need a reliable way to find past question papers, check campus
information, register for activities, recover belongings and follow up on
complaints. Teachers need to share course materials/notices and record
attendance. Administrators need to publish trusted campus updates and manage
staff access.

## Features

1. Resource Hub: file uploads, department/course/category/tag search, private
   visibility, PDF previews and downloads.
2. Smart Helpdesk: topic/keyword search, official source links, admin-managed
   FAQ answers and image/PDF attachments.
3. Club & Event Engine: discover events, RSVP, persistent ticket codes and
   staff check-in.
4. Lost & Found / Complaint Box: photo reports and resolution status; private
   complaints with receipt IDs, administrator replies and status tracking.
5. Additional: campus/course notices, course enrollment, recorded attendance,
   mobile navigation and password recovery.

## Technical implementation

React 18, JavaScript, Vite and CSS; Supabase Auth, PostgreSQL with row-level
security, and private Storage buckets. Smart Helpdesk is a structured FAQ
search, not an AI chatbot. No custom AI model is required for this version.
